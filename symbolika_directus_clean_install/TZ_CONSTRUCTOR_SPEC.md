# Конструктор ТЗ

Живая спецификация для будущего конструктора технических заданий.

Пользователь описывает логику текстом, а система должна хранить ее как набор:
- категория / подкатегория;
- маршрут производства;
- поля для заполнения менеджером;
- справочники значений;
- условия показа полей;
- формула итогового текста ТЗ.

## Общие принципы

- Количество берется из позиции заказа.
- Итоговый текст конструктора записывается в поле ТЗ позиции заказа.
- Поля конструктора должны быть максимально простыми для менеджера: выпадающие списки, галочки, числовые поля и текстовые поля только там, где нужен свой вариант.
- Все поля, которые отображаются в конструкторе, обязательны для заполнения.
- Условные поля обязательны только после включения соответствующей опции. Например, если ламинация не выбрана, тип и плотность ламинации не показываются и не заполняются.
- В каждой форме конструктора должно быть дополнительное свободное поле `Комментарий к ТЗ`.
- `Комментарий к ТЗ` не обязателен. Он нужен для уточнений, которые не укладываются в стандартные поля, например: `бейджей 3 вида: 1 вида 10 шт, второго 20 шт, третьего 30 шт`.
- Если комментарий заполнен, он добавляется в конец итогового ТЗ отдельной фразой: `Комментарий: {comment}`.

## Полиграфия

### Маршрутизация

- Категория: `Полиграфия`.
- По умолчанию автоматически отправляется в `Производство`.
- Маршрут: `контрагент 1 = Производство`.

### Общие справочники полиграфии

#### Бумага

- `80 гр офисная`.
- `130 гр мелованная`.
- `170 гр мелованная`.
- `200 гр мелованная`.
- `250 гр мелованная`.
- `300 гр мелованная`.
- `Дизайнерская`.
- `Крафт-бумага`.

Для всех мелованных бумаг нужен дополнительный выбор покрытия:
- `матовая`;
- `глянцевая`.

#### Форматы печати

- `А3`.
- `А4`.
- `А5`.
- `А6`.
- `А7`.
- `Визитки 90x60`.
- `Свой вариант`.

Если выбран `Свой вариант`, менеджер указывает:
- ширину изделия;
- высоту изделия.

#### Ламинация

В подкатегориях, где ламинация применима, показывать галочку `Ламинация`.

Если галочка включена, показать поля:

1. `Тип ламинации`.
   - Тип: выбор из списка.
   - Варианты: `матовая`, `глянцевая`, `софт-тач`.

2. `Плотность ламинации`.
   - Тип: выбор из списка.
   - Варианты зависят от типа ламинации:
     - `матовая`: `32 мкн`, `125 мкн`, `250 мкн`;
     - `глянцевая`: `32 мкн`, `125 мкн`, `250 мкн`;
     - `софт-тач`: `32 мкн`.

### Грамоты

#### Поля для заполнения

1. `Формат`.
   - Тип: выбор из списка.
   - Варианты: `А5`, `А4`, `А3`.
   - Для грамот другие форматы не показывать.

2. `Бумага`.
   - Тип: выбор из списка.
   - Варианты: из общего справочника бумаги.

3. `Покрытие бумаги`.
   - Тип: выбор из списка.
   - Показывать только если бумага мелованная.
   - Варианты: `матовая`, `глянцевая`.

4. `Цветность печати`.
   - Тип: выбор из списка.
   - Варианты: `4+0`, `1+0`.

5. `Количество`.
   - Не заполняется в конструкторе.
   - Берется из позиции заказа.

#### Итоговый текст ТЗ

Основной шаблон:

```text
{quantity} грамот формата {format}, бумага {paper_short}, {print_color}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{format}` = выбранный формат.
- `{paper_short}` = короткое название бумаги для ТЗ, например `300 гр`, `80 гр офисная`, `дизайнерская`, `крафт-бумага`.
- `{print_color}` = выбранная цветность.

Пример:

```text
20 грамот формата А4, бумага 300 гр, 4+0
```

Покрытие мелованной бумаги (`матовая` / `глянцевая`) хранится как отдельный параметр и может использоваться в производстве, но по умолчанию не добавляется в короткий текст ТЗ для грамот.

Если позже понадобится явно указывать покрытие, можно включить расширенный шаблон:

```text
{quantity} грамот формата {format}, бумага {paper_short}, {paper_finish}, {print_color}
```

### Визитки

#### Маршрутизация

- Основной маршрут: `контрагент 1 = Производство`.
- Если включен `УФ-лак`, дополнительно ставить `контрагент 2 = Шелкография`.

#### Поля для заполнения

1. `Бумага`.
   - Тип: выбор из списка.
   - Значение по умолчанию: `300 гр мелованная`.
   - Покрытие бумаги: `матовая`, `глянцевая`.

2. `Цветность печати`.
   - Тип: выбор из списка.
   - Варианты: `1+0`, `1+1`, `4+0`, `4+1`, `4+4`.

3. `Ламинация`.
   - Тип: галочка.
   - Если включена, показать общий блок полей ламинации.

4. `Скругление углов`.
   - Тип: галочка.

5. `УФ-лак`.
   - Тип: галочка.
   - Если включен, позиция дополнительно попадает в `Шелкография` вторым контрагентом.

6. `Количество`.
   - Не заполняется в конструкторе.
   - Берется из позиции заказа.

#### Итоговый текст ТЗ

Базовый шаблон:

```text
{quantity} визиток, бумага {paper_short} {paper_finish}, {print_color}{lamination_text}{rounded_corners_text}{uv_lacquer_text}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{paper_short}` = `300 гр`.
- `{paper_finish}` = `матовая` или `глянцевая`.
- `{print_color}` = выбранная цветность.
- `{lamination_text}` добавляется только если включена ламинация: `, ламинация {lamination_type} {lamination_density}`.
- `{rounded_corners_text}` добавляется только если включено скругление: `, скругление углов`.
- `{uv_lacquer_text}` добавляется только если включен УФ-лак: `, УФ-лак`.

Примеры:

```text
100 визиток, бумага 300 гр матовая, 4+4
```

```text
100 визиток, бумага 300 гр глянцевая, 4+4, ламинация матовая 32 мкн, скругление углов, УФ-лак
```

### Листовки

#### Маршрутизация

- Основной маршрут: `контрагент 1 = Производство`.

#### Поля для заполнения

1. `Формат`.
   - Тип: выбор из списка.
   - Варианты: `А7`, `А6`, `А5`, `А4`, `А3`, `Нестандарт`.
   - Если выбран `Нестандарт`, показать поля:
     - `Ширина`;
     - `Высота`.

2. `Бумага`.
   - Тип: выбор из списка.
   - Стандартные варианты: `130 гр мелованная`, `170 гр мелованная`.
   - Покрытие бумаги: `матовая`, `глянцевая`.

3. `Цветность печати`.
   - Тип: выбор из списка.
   - Варианты: `1+1`, `4+1`, `4+4`.

4. `Перфорация`.
   - Тип: галочка.

5. `Биговка`.
   - Тип: галочка.
   - Если включена, показать поле `Количество бигов`.

6. `Количество`.
   - Не заполняется в конструкторе.
   - Берется из позиции заказа.

#### Итоговый текст ТЗ

Базовый шаблон:

```text
{quantity} листовок формата {format}, бумага {paper_short} {paper_finish}, {print_color}{perforation_text}{creasing_text}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{format}` = выбранный формат или нестандартный размер в формате `{width}x{height}`.
- `{paper_short}` = `130 гр` или `170 гр`.
- `{paper_finish}` = `матовая` или `глянцевая`.
- `{print_color}` = выбранная цветность.
- `{perforation_text}` добавляется только если включена перфорация: `, перфорация`.
- `{creasing_text}` добавляется только если включена биговка: `, биговка {creasing_count} биг`.

Примеры:

```text
500 листовок формата А5, бумага 130 гр глянцевая, 4+0
```

```text
1000 листовок формата 210x98, бумага 170 гр матовая, 4+4, перфорация, биговка 2 бига
```

### Блокноты

#### Маршрутизация

- Основной маршрут: `контрагент 1 = Производство`.

#### Поля для заполнения

1. `Формат`.
   - Тип: выбор из списка.
   - Варианты: `А6`, `А5`, `А4`.

2. `Печать обложки`.
   - Тип: выбор из списка.
   - Бумага обложки всегда `300 гр мелованная`.
   - Варианты печати: `4+0`, `4+4`.

3. `Ламинация обложки`.
   - Тип: галочка.
   - Если включена, показать общий блок полей ламинации.

4. `Печать задника`.
   - Тип: выбор из списка.
   - Варианты: `Без печати`, `4+0`, `4+4`.

5. `Ламинация задника`.
   - Тип: галочка.
   - Если включена, показать общий блок полей ламинации.

6. `Количество листов внутреннего блока`.
   - Тип: число.
   - Значение по умолчанию: `40`.
   - Менеджер может указать свое значение заполнения блокнота.

7. `Запечатка внутреннего блока`.
   - Тип: выбор из списка.
   - Бумага внутреннего блока: `80 гр офисная`.
   - Варианты: `Без запечатки`, `1+0`, `1+1`.

8. `Вид запечатки внутреннего блока`.
   - Тип: выбор из списка.
   - Показывать только если запечатка внутреннего блока не `Без запечатки`.
   - Варианты: `Клетка`, `Линейка`, `По макету заказчика`.

9. `Информационный блок перед внутренним блоком`.
   - Тип: галочка.
   - Если включен, показать поля:
     - `Количество листов информационного блока`;
     - `Цветность печати информационного блока`;
     - `Плотность бумаги информационного блока`.

10. `Расположение пружины`.
    - Тип: выбор из списка.
    - Варианты: `Сверху`, `Слева`.

11. `Цвет пружины`.
    - Тип: выбор из списка.
    - Варианты: `Белая`, `Черная`.

12. `Количество`.
    - Не заполняется в конструкторе.
    - Берется из позиции заказа.

#### Итоговый текст ТЗ

Базовый шаблон:

```text
{quantity} блокнотов формата {format}, обложка 300 гр {cover_print}{cover_lamination_text}, задник {back_print}{back_lamination_text}, внутренний блок {inner_sheets_count} листов 80 гр офисная{inner_print_text}{info_block_text}, пружина {spring_position}, {spring_color}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{format}` = выбранный формат.
- `{cover_print}` = печать обложки.
- `{cover_lamination_text}` добавляется только если включена ламинация обложки: `, ламинация {lamination_type} {lamination_density}`.
- `{back_print}` = `без печати`, `4+0` или `4+4`.
- `{back_lamination_text}` добавляется только если включена ламинация задника: `, ламинация {lamination_type} {lamination_density}`.
- `{inner_sheets_count}` = количество листов внутреннего блока, по умолчанию `40`.
- `{inner_print_text}`:
  - если внутренний блок без запечатки: не добавляется;
  - если включена запечатка: `, {inner_print_color}, {inner_print_type}`.
- `{info_block_text}` добавляется только если включен информационный блок: `, перед блоком {info_sheets_count} листов, {info_print_color}, бумага {info_paper_density}`.
- `{spring_position}` = `сверху` или `слева`.
- `{spring_color}` = `белая` или `черная`.

Примеры:

```text
50 блокнотов формата А5, обложка 300 гр 4+0, ламинация матовая 32 мкн, задник без печати, внутренний блок 40 листов 80 гр офисная, 1+0, клетка, пружина сверху, черная
```

```text
30 блокнотов формата А4, обложка 300 гр 4+4, задник 4+0, ламинация глянцевая 32 мкн, внутренний блок 60 листов 80 гр офисная, 1+1, по макету заказчика, перед блоком 4 листа, 4+4, бумага 170 гр, пружина слева, белая
```

### Бейджи

#### Маршрутизация

- Основной маршрут: `контрагент 1 = Производство`.

#### Поля для заполнения

1. `Формат`.
   - Тип: выбор из списка.
   - Варианты: `А7`, `А6`, `Свой размер`.
   - Если выбран `Свой размер`, показать поля:
     - `Ширина`;
     - `Высота`.

2. `Бумага`.
   - Значение по умолчанию: `300 гр мелованная`.

3. `Цветность печати`.
   - Тип: выбор из списка.
   - Варианты: `4+0`, `4+4`.

4. `Ламинация`.
   - Тип: галочка.
   - Если включена, показать общий блок полей ламинации.

5. `Скругление углов`.
   - Тип: галочка.

6. `Тип отверстия`.
   - Тип: обязательный выбор из списка.
   - Варианты: `Под карабин`, `Под два карабина`, `Под крокодил`.
   - Значение должно быть выбрано всегда.

7. `Количество`.
   - Не заполняется в конструкторе.
   - Берется из позиции заказа.

#### Итоговый текст ТЗ

Базовый шаблон:

```text
{quantity} бейджей формата {format}, бумага 300 гр, {print_color}{lamination_text}{rounded_corners_text}, отверстие {hole_type}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{format}` = выбранный формат или свой размер в формате `{width}x{height}`.
- `{print_color}` = выбранная цветность.
- `{lamination_text}` добавляется только если включена ламинация: `, ламинация {lamination_type} {lamination_density}`.
- `{rounded_corners_text}` добавляется только если включено скругление: `, скругление углов`.
- `{hole_type}` = выбранный тип отверстия.

Примеры:

```text
50 бейджей формата А7, бумага 300 гр, 4+0, ламинация матовая 125 мкн, скругление углов, отверстие под карабин
```

```text
20 бейджей формата 100x70, бумага 300 гр, 4+4, ламинация глянцевая 250 мкн, отверстие под два карабина
```

### Календари / Карманные

```text
{quantity} карманных календарей 100x70 мм, бумага 300 гр, {print_color}, ламинация {lamination_type}{rounded_corners_text}
```

Правила сборки:
- `{quantity}` = количество из позиции.
- `{print_color}` = выбранная цветность.
- `{lamination_type}` = `матовая` или `глянцевая`.
- `{rounded_corners_text}` добавляется только если включено скругление: `, скругление углов`.

Примеры:


```text
500 карманных календарей 100x70 мм, бумага 300 гр, 4+4, ламинация матовая, скругление углов
```

### Закладки

   - Тип: поля размера.
   - Менеджер указывает:
     - `Ширина`;
     - `Высота`.

2. `Бумага`.
   - Значение по умолчанию: `300 гр мелованная`.

3. `Цветность печати`.
   - Тип: выбор из списка.

### Маршрутизация

- Категория: `Текстиль`.
- Детализация: вид нанесения.
- Название позиции считается названием заготовки, например `Футболки`, `Поло`, `Свитшоты`.
- Количество берется из карточки позиции заказа.

### Общие правила

- `{product_name}` = наименование позиции заказа.
- `{quantity}` = количество из позиции заказа.
- Для всего текстиля обязательно указывается `Цвет изделия`.
- Для футболок, поло, худи, лонгсливов, свитшотов и другого размерного текстиля показывается размерный ряд `XS`–`5XL` с количеством по каждому размеру.
- Сумма количества по размерам должна совпадать с количеством позиции заказа. Для текстиля без размерного ряда блок можно отключить.

- В зависимости от количества принтов показываются группы полей для нанесения 1, 2, 3 и 4.
- В интерфейсе `Размер нанесения {n}` и `Кол-во цветов нанесения {n}` располагаются рядом в одной группе.
- Максимальное количество принтов: `4`.

## Конструкции

### Маршрутизация

- Категория: `Конструкции`.
- Детализация: подкатегории.
- Количество берется из позиции заказа.
- Для `Ролап` и `Виндер` подрядчики определяются по обычным правилам маршрутизации выбранной подкатегории/производственного участка.
- Для `Джокер` и `Брус` используется составная маршрутизация:
  - `Подрядчик 1` — контрагент для печати баннеров по правилам категории `Баннеры`;
  - `Подрядчик 2` — контрагент, ответственный за монтаж;
  - для выбора монтажного контрагента у контрагентов нужно добавить признак `Возможность монтажа`;
  - в список монтажных подрядчиков попадают только контрагенты с включенным признаком `Возможность монтажа`.

#### Поля для заполнения

1. `Тип ролапа`.
   - Тип: выбор из списка.

     - `Другой размер`.

3. `Ширина баннера, мм`.
   - Тип: число.
   - Показывать, если:
     - `Тип ролапа` = `Замена полотна в конструкции заказчика`;
     - или `Размер баннера` = `Другой размер`.

4. `Высота баннера, мм`.
   - Тип: число.
   - Показывать, если:
     - `Тип ролапа` = `Замена полотна в конструкции заказчика`;
     - или `Размер баннера` = `Другой размер`.

#### Итоговый текст ТЗ

Для замены полотна:

```text
{quantity} полотен для ролапа в конструкцию заказчика, размер {width}x{height} мм
```

Для ролапа с нашей конструкцией:

```text
{quantity} ролапов с баннером, размер {size}
```

Если выбран `Другой размер`, `{size}` заменяется на `{width}x{height} мм`.

Примеры:

```text

```

```text
2 ролапа с баннером, размер 85x200 см
```

   - Тип: галочка.

4. `Нужны пригрузы`.
   - Тип: галочка.

5. `Наш монтаж`.
   - Тип: галочка.

- Если включено `Наш монтаж`, добавить `, наш монтаж`.

Пример:

```text
1 конструкция из бруса, размер 3000x2000 мм, нужны откосы, нужны пригрузы, наш монтаж
```
