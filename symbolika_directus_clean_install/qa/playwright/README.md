# Playwright QA

Постоянный smoke-набор для рабочих модулей «Символики». Конструктор ТЗ набор не открывает и не изменяет.

Набор:

- проверяет вход и модули админа, управляющего, менеджера, офиса, производства, шелкографии и дизайнера;
- ищет видимые `Failed to fetch` и другие error-баннеры;
- проверяет горизонтальное переполнение и рабочие элементы за границами viewport;
- проверяет липкую панель заказов;
- открывает позицию из списка и повторно проверяет её deep-link после reload;
- всегда удаляет созданных QA-пользователей.

## Запуск

```powershell
cd symbolika_directus_clean_install\qa\playwright
npm.cmd install
$env:SYMBOLIKA_QA_ADMIN_TOKEN='local-admin-static-token'
npm.cmd test
```

Для видимого браузера:

```powershell
npm.cmd run test:headed
```

Токены ролей из `.env.example` необязательны. Если они заданы, UI-запросы к `/items/*` проверяются на репрезентативных данных этой роли. Все секреты передаются только через environment.

Для быстрой проверки только отдельных ролей можно задать, например, `$env:SYMBOLIKA_QA_ROLES='admin,designer'`.

Результат записывается в `qa-results/report.json`. Скриншот сохраняется для каждой упавшей проверки.
